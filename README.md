# Ritmik Sayma Macerası 🌟

**Sayıları öğren, yıldızları topla, bayrağa ulaş!**

**Ritmik Sayma Macerası**, Türkiye'deki 3. sınıf öğrencileri (8–10 yaş) için özel olarak tasarlanmış, 3B animasyon estetiğine sahip eğitici bir yandan görünümlü (side-scrolling) platform oyunudur. Hem masaüstü klavyeyle hem de sınıflardaki **Etkileşimli Tahta (Akıllı Tahta)** üzerinde dokunmatik olarak oynanabilir.

---

## 🎮 Özellikler

- **2'den 10'a Kadar İleriye ve Geriye Ritmik Saymalar:**
  - **2'şer, 3'er, 4'er, 5'er, 6'şar, 7'şer, 8'er, 9'ar ve 10'ar** ritmik sayma aralıklarının tamamını içerir.
  - Hem **İleriye Doğru (`➡ İleriye Ritmik Sayma`)** hem de **Geriye Doğru (`⬅ Geriye Ritmik Sayma`)** örüntü sorularını destekler.
  - **Dünyalar (2-10 Seç)** ekranından istenilen sayma adımı (2–10) ve sayma yönü (İleriye / Geriye / Karışık) doğrudan seçilerek de oynanabilir.
- **Zıplama Tuşuna Basılı Tutarak Havada Kalma (Süzülme) Özelliği:**
  - Zıplama tuşuna (**Yukarı Yön Tuşu `⬆`**, **`Boşluk`** veya Etkileşimli Tahtadaki **`⬆ ZIPLA / HAVADA KAL`** düğmesi) basılı tutulduğu sürece karakter havada yükselir ve süzülür.
  - Öğrenciler havada süzülerek en arkadaki cevap kutusunun üzerine kadar rahatça ilerleyebilir ve tuşu bıraktıklarında doğrudan istedikleri kutunun üzerine inebilirler.
  - Ayrıca tüm cevap kutuları alttan yukarıya geçilebilir (*one-way platform*) yapıdadır; karakter kutuların altına çarparak takılmaz.
- **Etkileşimli Tahta (Akıllı Tahta) Dokunmatik Kontrol Bölümü:**
  - Oyun ekranının alt kısmında Etkileşimli Tahta kullanımı için özel dokunmatik kontrol paneli yer alır:
    - **`⬅ SOLA GİT`** ve **`SAĞA GİT ➡`**
    - **`↖ SOLA ZIPLA`** (Tek parmakla hem sola gitme hem zıplama/havada kalma)
    - **`⬆ ZIPLA / HAVADA KAL`** (Basılı tutulduğu sürece havada tutar)
    - **`↗ SAĞA ZIPLA`** (Tek parmakla hem sağa gitme hem zıplama/havada kalma)
- **5 Özgün Oynanabilir Kahraman:**
  1. **Kırmızı Kaşif** — Cesur Macera Öncüsü
  2. **Yeşil Kaşif** — Neşeli Orman Gezgini
  3. **Prenses Lila** — Bilge Yıldız Gezgini
  4. **Mantar Dost** — Sevimli Orman Rehberi
  5. **Dino Pati** — Sevimli Dinozor Yoldaş
- **5 Farklı Dünya ve 15 Macera Bölümü + Serbest Seçim Modu:**
  - **1. Dünya: Yeşil Krallık** (*2'şer, 5'er ve 10'ar İleri ve Geri Ritmik Sayma*)
  - **2. Dünya: Mantar Ormanı** (*3'er ve 4'er İleri ve Geri Ritmik Sayma*)
  - **3. Dünya: Sayı Çölü** (*6'şar ve 7'şer İleri ve Geri Ritmik Sayma*)
  - **4. Dünya: Bulut Krallığı** (*8'er ve 9'ar İleri ve Geri Ritmik Sayma*)
  - **5. Dünya: Büyülü Kale** (*2'den 10'a Karışık İleri ve Geri Ritmik Sayma*)

## ⌨️ Klavye ve Etkileşimli Tahta Kontrolleri

| Kontrol | İşlev |
| :--- | :--- |
| **Sol Yön Tuşu (`⬅`)** veya **`⬅ SOLA GİT`** | Sola hareket et |
| **Sağ Yön Tuşu (`➡`)** veya **`SAĞA GİT ➡`** | Sağa hareket et |
| **Yukarı Yön Tuşu (`⬆`)**, **`Boşluk`** veya **`⬆ ZIPLA / HAVADA KAL`** | Zıpla (Basılı tutulduğunda havada kalır / süzülür) |
| **`↖ SOLA ZIPLA`** / **`↗ SAĞA ZIPLA`** | Etkileşimli tahtada tek dokunuşla çapraz zıplama ve havada süzülme |
| **`Esc`** | Oyunu duraklat / Duraklatma menüsünü aç |

## 🚀 Kurulum ve Çalıştırma

```bash
# 1. Bağımlılıkları yükleyin
npm install

# 2. Geliştirme sunucusunu başlatın (http://localhost:5173)
npm run dev

# 3. Üretim (production) derlemesi alın
npm run build
```
